## Abstract

The **Survey Data Analysis Tool** is a Python-based Data Science project developed to collect, process, analyze, and visualize survey responses to identify meaningful patterns and relationships in students' social media usage behaviour.

The project will use survey responses collected through Google Sheets, along with suitable public datasets such as the Social Media Students Dataset (2025), Student Social Media Addiction Analysis Dataset, and Student Social Media & Academic Performance Dataset from Kaggle.

The project follows an end-to-end workflow:

**Data Collection → Data Preprocessing → EDA → Statistical Analysis → Machine Learning → Dashboard → Insights**

Data preprocessing will handle missing values, duplicate records, inconsistencies, and other data-quality issues. Exploratory Data Analysis (EDA) will be performed to study distributions, trends, patterns, and relationships among variables such as daily usage time, usage frequency, preferred platforms, and app-checking behaviour.

Statistical analysis will include correlation, covariance, hypothesis testing, and Chi-square testing to identify significant relationships between selected variables.

For the Machine Learning component, classification techniques such as Logistic Regression, Decision Tree, Random Forest, K-Nearest Neighbours (KNN), and Support Vector Machine (SVM) will be explored to classify students into **Low, Moderate, and Heavy Social Media Users**.

Model performance will be evaluated using metrics such as accuracy, precision, recall, F1-score, and confusion matrix. The ML model will classify users based on factors such as age, daily usage time, usage frequency, number of app checks, preferred platform, and other usage patterns.

An interactive **Power BI dashboard** will present survey statistics, visualizations, category comparisons, statistical findings, and ML results.

The final system will generate meaningful data-driven insights into students' social media usage patterns and demonstrate the complete Data Science workflow from raw data collection to preprocessing, analysis, machine learning, dashboard visualization, and insight generation.

## Objectives

- Collect and organize survey responses from Google Sheets and suitable public datasets.
- Clean and preprocess the collected survey data.
- Handle missing values, duplicate records, inconsistencies, and data-quality issues.
- Perform Exploratory Data Analysis (EDA) to identify patterns, trends, distributions, and relationships.
- Apply statistical techniques to identify meaningful relationships between variables.
- Develop Machine Learning models to classify students based on their social media usage levels.
- Evaluate Machine Learning models using standard performance metrics.
- Develop an interactive Power BI dashboard to present analytical findings.
- Generate meaningful data-driven insights from student social media usage patterns.

## Data Sources

The project can use survey responses collected through **Google Forms/Google Sheets** along with suitable public datasets.

Example datasets include:

- Social Media Students Dataset (2025)
- Student Social Media Addiction Analysis Dataset
- Student Social Media & Academic Performance Dataset
- Custom survey responses collected through Google Forms and Google Sheets

The tool is designed to work with structured survey datasets and is not restricted to a single dataset.
